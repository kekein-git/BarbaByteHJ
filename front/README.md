# Pasta `front`

Contem a interface visual do CRM.

## Estrutura

- `templates/`: paginas HTML renderizadas pelo Flask.
- `static/css/`: estilos globais do sistema.
- `static/js/`: comportamentos simples do frontend.

## Objetivo visual

- Cor primaria: azul escuro.
- Base visual: branco e tons neutros.
- Layout responsivo para desktop e mobile.
